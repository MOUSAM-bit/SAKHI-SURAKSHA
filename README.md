# SakhiSuraksha 🚨

An emergency response and personal safety web application designed for rapid SOS alerts, real-time location tracking, and multi-language accessibility.

## ✨ Key Features

- **Voice-Activated SOS:** Hands-free emergency triggering using client-side keyword detection via the Web Speech API.
- **Real-Time Geolocation:** Captures and transmits accurate live coordinates using the HTML5 Geolocation API.
- **Instant Alert Dispatch:** Sends automated emergency notifications via asynchronous SMTP email dispatch.
- **Multilingual Support:** Built-in localization supporting 22 regional languages for broad accessibility.

## 🛠️ Tech Stack

- **Backend:** Node.js, Express (`server.js`)
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **APIs & Services:** Web Speech API, HTML5 Geolocation API, Nodemailer (SMTP)
